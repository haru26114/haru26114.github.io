这是我最近做的一道比较简单的贪心洛谷题目，但是思路策略的过程我觉得十分经典，故写下这篇。
洛谷原题链接

思路过程

–
先审题，看数据量（十分十分重要，因为这不仅针对时间复杂度的情况制定相应策略，还要确定你的思考方向）

对于大部分人来说这题一看就想出最优解，但对于我这种(～￣(OO)￣)ブ笨鼠鼠，可能第一时间没太大思路，那最好的最优选就是暴力，因为不仅从做题的角度来讲可以适当“骗分”，而且对于这种类似贪心的题目，无法在短时间内去证明你的思路或策略结论是对的（贪心证明有时候真的很难*——*），所以不妨就把暴力方案作为一种对数器，去快速验证你的思路

所以从暴力的角度来说，用两个数组一个记录原数组变化，一个记录最大值，再用双指针去向左右扩散，便能求出解，c嘎嘎代码如下

#include <iostream> #include <algorithm> #include<queue> using namespace std; const int maxn = 1e6; int n; long long a[maxn]; long long p1[maxn]; long long p2[maxn]; int l, r; int main() { int m; cin >> n >> m; fill(p1 + 1, p1 + n+1, 0); fill(p2 + 1, p2 + n+1, 0); for (int i = 1; i <= m; i++) { cin >> a[i]; l = a[i]; r = a[i]; while (l != 1 || r != n) { if (l - 1 >= 1) { l--; p1[l] = 1 + p1[l+1]; p2[l] = max(p2[l], p1[l]); } if (r + 1 <=n) { r++; p1[r] = 1 + p1[r-1]; p2[r] = max(p2[r], p1[r]); } } fill(p1 +1, p1 + n+1, 0); } for (int i = 1; i <= n; i++) { cout << p2[i] << " "; } }

复杂度一看肯定过不了，毕竟for套while还全遍历数组。

在写完的同时，是不是对n左右扩散加1的行为有种熟悉感，这不tm就是距离绝对值嘛，而且我们注意到n位置的最大只与左右最大最小有关（因为不知道n是靠左还是靠右），因此只要记录这两值对每个位置相减即可得出答案
`
#include
#include
#include
#include
using namespace std;
const int maxn = 1e6;
int n,m;
long long a[maxn];
long long p1[maxn];
int main()
{
long long mmax=-1;
long long mmin = maxn;
cin >> n >> m;
for (int i = 1; i <= m; i++)
{
cin >> a[i];
mmax = max(mmax, a[i]);
mmin = min(mmin, a[i]);
}
for (int i = 1; i <= n; i++)
{
p1[i] = max(abs(i - mmax), abs(i - mmin));
cout << p1[i] << “ “;
}
}

`

结语

类似贪心的题目一开始就想到最优解基本上是不可能的吧？，所以先暴力得对数器，在暴力的同时也能发掘一个个突破口从而攻破这道题。
